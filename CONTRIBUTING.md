
# Contributing to FastCleaner

Thank you for your interest in contributing to FastCleaner!

## How to contribute

You can help by:

- Reporting bugs
- Suggesting new features
- Improving the interface or documentation
- Fixing issues
- Submitting pull requests

## Reporting bugs

When reporting a bug, include:

- Windows version
- .NET version
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Screenshots or error messages, if available

## Development setup

1. Fork the repository.
2. Clone your fork:

```bash
git clone https://github.com/your-username/FastCleaner.git
cd FastCleaner
```

3. Open `FastCleaner.sln` in Visual Studio.
4. Build and run the project.

## Pull requests

Before submitting a pull request:

- Keep changes focused on one feature or fix.
- Test the application before submitting.
- Write clear commit messages.
- Do not include unrelated files or build output.
- Explain what your pull request changes.

## Safety first

FastCleaner handles file deletion. Contributions must prioritize user safety:

- Never delete files without user confirmation.
- Avoid scanning unrelated folders.
- Clearly show users what will be removed.
- Preserve error handling for protected or in-use files.

Thank you for helping improve FastCleaner!
